Questions for the estate agent

In Sweden the estate agent (mäklare) works for the seller, but has to answer you correctly — on what you ask. This list adapts to the type of property. Every question comes with the Swedish wording, so you can ask it in Swedish too.

What kind of property is it?

What this list can’t do: make sense of the answers. “The association has 18,000 kr of debt per square metre” sounds like a number and is really a judgement call.

If you have the documents and want someone to read them: Property check, 149 € — two pages in English, usually within two working days.
